# GO Evolutionary Dimensions

This repository contains supplementary materials for a study examining the evolution of the Gene Ontology (GO) as a biomedical knowledge organization system and research infrastructure.

The project uses the **GO Evolutionary Dimensions Framework (GEDF)** to analyze how GO-related research has developed across disciplinary, methodological, and epistemic dimensions. The current repository provides visual materials associated with the manuscript submission.

## Chord Plots

The `figures/GEDF-chord-plots/` folder contains four chord plots corresponding to the major GEDF dimensions:

1. **Functional sophistication**
2. **Automation degree**
3. **Reasoning and inference capability**
4. **Quality control and validation**

These visualizations illustrate relationships among GO-related research categories and support the analysis presented in the manuscript.
